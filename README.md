# Business Day Calculate

A fast, browser-based Business Day Calculator built with plain HTML, CSS and JavaScript.

## Features

- Business days between two dates
- Monday-Friday or Monday-Saturday schedules
- Custom working days
- Optional holiday exclusion
- Include/exclude start and end dates
- Calendar and weekend day counts
- Copy results
- Responsive design
- No external JavaScript libraries
